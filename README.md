# Programa-simple-descargar-contenido

Aplicación de escritorio en Java para descargar audio de internet de forma automática con yt-dlp. Este proyecto incluye configuraciones optimizadas para evadir bloqueos de servidores como el error HTTP 403 Forbidden. También está blindado contra fallas en enlaces de listas de reproducción y guarda los archivos MP3 directamente en la carpeta de descargas.

## 🛠️ Requisitos
* **Java 21** (o superior)
* **yt-dlp** instalado en las variables de entorno
* **FFmpeg** configurado en el sistema para la conversión a MP3
